# Unity UI

[Unity UI](../../../unity-ui-skill/SKILL.md) defaults to UI Toolkit. [Hierarchy and reuse](../../../unity-ui-skill/references/layout-and-input.md#hierarchy-and-reuse) covers template lifetime, alignment and Canvas parity. [Screen adaptation](../../../unity-ui-skill/references/screen-adaptation.md) covers proportional artwork and projection, navigation and readable text over progress. The [profile configuration](../../../unity-ui-skill/assets/screen-layouts.json) and [Unity geometry reader](../../../unity-ui-skill/assets/ScreenLayoutPolicy.cs) define five base compositions and local obstruction handling. The [iPhone Duo capture cases](../../../unity-ui-skill/references/screen-profiles.md#capture-each-iphone-duo-display-separately) verify the upper-left and lower-right outer landscape poses projected from one physical aperture, and clear inner portrait and landscape frames with the camera inactive. [Artwork intake](../../../unity-ui-skill/references/artwork-intake.md#yofaassets-split-to-unity) defines the YoFaAssets handoff.

[Localized content](../../../unity-ui-skill/references/layout-and-input.md#localized-content) requires resource keys and locale refresh from the first screen. It owns the player-facing text inventory, locale-formatted data, font coverage, and the language, state and viewport matrix.

The [five native layout examples](../../../examples/charge-pulse/README.md#responsive-ui-cases) cover HUD cutouts, inventory reuse, settings alignment, a Toolkit and Canvas confirmation dialog, and a bounded scrolling journal. All five read their text from the [fixture string table](../../../examples/charge-pulse/Assets/Editor/Tests/ResponsiveLayouts/LayoutStrings.json). Their test entry points belong to the repository catalog module.
