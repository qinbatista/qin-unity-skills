# Unity UI

[Unity UI](../../../unity-ui-skill/SKILL.md) defaults to UI Toolkit. [Hierarchy and reuse](../../../unity-ui-skill/references/layout-and-input.md#hierarchy-and-reuse) covers template lifetime, alignment and Canvas parity. [Screen adaptation](../../../unity-ui-skill/references/screen-adaptation.md) covers proportional artwork and projection, navigation and readable text over progress. The [profile configuration](../../../unity-ui-skill/assets/screen-layouts.json) and [Unity geometry reader](../../../unity-ui-skill/assets/ScreenLayoutPolicy.cs) define five base compositions and local obstruction handling. The [iPhone Duo capture cases](../../../unity-ui-skill/references/screen-profiles.md#capture-each-iphone-duo-display-separately) cover the upper-right outer portrait aperture, its two landscape turns, and clear inner portrait and landscape with the camera inactive. [Artwork intake](../../../unity-ui-skill/references/artwork-intake.md#yofaassets-split-to-unity) defines the YoFaAssets handoff. [Resizable buttons and panels](../../../unity-ui-skill/references/artwork-intake.md#resize-buttons-and-panels) owns the reusable Toolkit backing and corresponding Canvas settings. Reproduce both hosts through the [installed image replay](../../../unity-performance-skill/references/performance-cases.md#replay-the-image-optimization-examples). See the [illustrated native controls](../../../examples/image-optimization/README.md#one-backing-for-a-panel-and-two-buttons) for source art, Toolkit hit testing and the Canvas render.

For a screen adaptation request, use [adapt an existing screen](../../../unity-ui-skill/SKILL.md#adapt-an-existing-screen) and [set bounds for each group](../../../unity-ui-skill/references/screen-adaptation.md#set-bounds-for-each-group). Use [the group’s declared center](../../../unity-ui-skill/references/screen-adaptation.md#center-a-group-within-its-declared-bounds) to distinguish a safe-area midpoint from a pane anchor that moves only for clearance. Verify the receiver's current configuration, restored anchors and display transfers with the [layout regression](../../../unity-ui-skill/references/screen-profiles.md#screen-adaptation-regression).

For UI Toolkit construction and repair, [inspect the mounted UXML tree](../../../unity-ui-skill/references/layout-and-input.md#import-and-inspect-the-mounted-tree) for template sizing, instance-scoped binding, reuse and text contrast on the painted background. [Action feedback](../../../unity-ui-skill/references/layout-and-input.md#give-actions-visible-feedback) covers stable hit targets, interrupted presses and reduced motion.

[Localized content](../../../unity-ui-skill/references/layout-and-input.md#localized-content) requires resource keys and locale refresh from the first screen. It owns the player-facing text inventory, locale-formatted data, font coverage, and the language, state and viewport matrix.

The [native screen inventory and device matrix](../../../examples/charge-pulse/UI-CASES.md) pairs all ten primary fixtures with their child states, control actions, 25 device profiles and scope of runtime evidence. Use [inventory and test a whole UI](../../../unity-ui-skill/references/layout-and-input.md#inventory-and-test-a-whole-ui) for a receiving game's route inventory. The [fixture string table](../../../examples/charge-pulse/Assets/Editor/Tests/ResponsiveLayouts/LayoutStrings.json) owns the two sample locales. The [compact HUD regression](../../../examples/charge-pulse/README.md#compact-hud-regression) documents the measured label repair. The [Duo Simulator capture](../../../examples/charge-pulse/duo-outer-dialog.png) shows the German confirmation on the outer display.
