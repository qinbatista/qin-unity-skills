The [five-mode storage audit](../../../unity-code-skill/references/so-data-controller.md#audit-storage-cost-by-mode) maps instance lifetime, snapshot replacement, caller-thread key writes, cloud receipt queues and replicated field updates to their native workloads. The native writer reserves its shared staging file and key per directory, allowing independent snapshots and offline keys to commit concurrently. [Identical values](../../../unity-code-skill/references/so-data-controller.md#skip-identical-values) skip storage and extra change events. Incoming equal payloads still advance the accepted revision.
