# Unity Assets

[Unity Assets](../../../unity-assets-skill/SKILL.md) routes feature packages, Editor-only code and GUID-preserving moves. Dedicated effect verification scenes live with the effect. [Texture intake](../../../unity-assets-skill/references/texture-intake.md) audits images touched by the task and owns the portable 1000 PPU world-Sprite default, platform compression, Crunch selection and independent native import/readback. Project-specific settings take precedence. Linked games use `explain texture-compression` for the registered image workflow and `explain unity-project` for the eight-root layout.
