# Unity Tech Explain

[Unity Tech Explain](../../../unity-tech-explain-skill/SKILL.md#write-the-answer) owns the unnumbered answer format across the seven technical domains. Use the receiving game’s own SO, its accessors and its gameplay methods. Show the filename and declaring type around the operation, then its ordinary public call. The [wallet walkthrough](../../../unity-tech-explain-skill/references/scriptableobject-storage.md) uses the shared SOCurrencyData template to follow one credit from its private setter to cold restart.

The [global routing rule](../../../unity-code-skill/references/global-skill-routing.md#require-routing-across-projects) opens the installed Skill for ordinary explanation requests. Direct domain entries link to the same format. Verify both through the [project test map](../../../.agents/skills/testing-skill/SKILL.md).
