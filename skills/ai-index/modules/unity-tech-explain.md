# Unity Tech Explain

[Unity Tech Explain](../../../unity-tech-explain-skill/SKILL.md#write-the-answer) owns the unnumbered answer format across the seven technical domains. For C# excerpts, show the source filename and the declaring type around the field. Give calls from another file their own class and method context. Follow the user action to its result. The [wallet walkthrough](../../../unity-tech-explain-skill/references/scriptableobject-storage.md) follows one real integer from pickup to cold restart.

The [global routing rule](../../../unity-code-skill/references/global-skill-routing.md#require-routing-across-projects) opens the installed Skill for ordinary explanation requests. Direct domain entries link to the same format. Verify both through the [project test map](../../../.agents/skills/testing-skill/SKILL.md).
