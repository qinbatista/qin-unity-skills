# Unity Tech Explain

[Unity Tech Explain](../../../unity-tech-explain-skill/SKILL.md#write-the-answer) owns the presentation of Unity answers across the seven technical domains. It uses the selected project and domain sources for facts. The [wallet walkthrough](../../../unity-tech-explain-skill/references/scriptableobject-storage.md) shows the expected depth with the portable Unity Code save example.

The [global routing rule](../../../unity-code-skill/references/global-skill-routing.md#require-routing-across-projects) opens the installed Skill for ordinary explanation requests. Direct domain entries link to the same format. Verify both through the [project test map](../../../.agents/skills/testing-skill/SKILL.md).
