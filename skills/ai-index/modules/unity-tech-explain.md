# Unity Tech Explain

[Unity Tech Explain](../../../unity-tech-explain-skill/SKILL.md#write-the-answer) owns the unnumbered answer format across the seven technical domains. It uses the selected project and domain sources for facts. The [wallet walkthrough](../../../unity-tech-explain-skill/references/scriptableobject-storage.md) shows how to use a plain-text branch diagram to explain a keyed coin commit, a concurrent write, and cold restart outcomes.

The [global routing rule](../../../unity-code-skill/references/global-skill-routing.md#require-routing-across-projects) opens the installed Skill for ordinary explanation requests. Direct domain entries link to the same format. Verify both through the [project test map](../../../.agents/skills/testing-skill/SKILL.md).
