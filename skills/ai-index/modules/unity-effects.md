# Unity Effects

Use the [reuse and creation workflow](../../../unity-effects-skill/SKILL.md#use-an-existing-effect-or-reference) to select the source, bind it to the receiving renderer and lifecycle, and verify native behavior. YoFaAssets supplies the VFX and Shader libraries and exact reference readback for linked work.

[Unity Effects](../../../unity-effects-skill/SKILL.md) routes [staged effects](../../../unity-effects-skill/references/staged-effects.md) for lifecycle, progressive shapes and layers, and [rendering and verification](../../../unity-effects-skill/references/rendering-and-verification.md) for native VFX and shader work. YoFaAssets owns its catalog, required linked-game profile and library handoff. The game owns triggers, budgets and assets.
