# Unity Testing

[Unity Testing](../../../unity-testing-skill/SKILL.md) chooses the smallest claim-bound case and cleans consumed task output. [Runtime and artifact evidence](../../../unity-testing-skill/references/runtime-and-artifact-evidence.md) owns package readback, native replay, [playable scene review](../../../unity-testing-skill/references/runtime-and-artifact-evidence.md#playable-scene-review), performance and [macOS batch recovery](../../../unity-testing-skill/references/runtime-and-artifact-evidence.md#macos-batch-startup). Verify this package through the [repository test map](../../../.agents/skills/testing-skill/SKILL.md).

[Isolated test packaging](../../../unity-testing-skill/references/runtime-and-artifact-evidence.md#isolated-test-packaging) freezes the current saved game inputs in a fresh Workflow run, builds from the copy and releases it after verification. Select the canonical YoFaPublisher workflow before staging whenever that route owns the package.

The [Charge Pulse macOS package smoke](../../../examples/charge-pulse/README.md#run-a-macos-package-smoke-test) checks the bundle, headless startup, native preference isolation and registered run cleanup.

The [SO device probe](../../../.agents/skills/testing-skill/SKILL.md#run-the-so-device-probe) prepares an external iOS receiver from the installed template. Its [preparer](../../../.agents/skills/testing-skill/tests/prepare_so_device_probe.py), [Editor builder](../../../.agents/skills/testing-skill/tests/Editor/SODeviceProbeBuilder.cs) and [Player observer](../../../.agents/skills/testing-skill/tests/fixtures/scriptableobjects/SODeviceProbe.cs) own six-mode assignment, duplicate suppression, real provider readback, cold reopening and cleanup. Keep this automated probe out of game runtime assemblies and published Skill payloads.
