# Structure and ownership

Keep each public Skill's instructions and references in its own package from the [catalog](../../../README.md). Unity Code owns the C# checker and its tests. Project routing lives in this index. The receiving game owns authored assets, implementation, and runtime tests.

Unity Assets and Unity Code share the [existing-game architecture workflow](../../../unity-code-skill/references/unity-cli.md#existing-game-architecture) for verified layouts and feature walkthroughs. The [game code structure rules](../../../unity-code-skill/references/unity-game-code-structure-design.md#ownership) apply to proposed code and examples as well as implementation.
