# qin-unity-skills

Reusable Unity and C# coding guidance for Codex.

- [Unity Code](unity-code-skill/SKILL.md) covers C# style, gameplay structure, lifecycle and serialization, and service integration. It includes a Python CLI that checks C# source and Git diffs.
- The [project AI index](skills/ai-index/SKILL.md) routes work on this repository. The [testing Skill](.agents/skills/testing-skill/SKILL.md) maps the maintained tests to their runners.

Place the `unity-code-skill` folder under `~/.agents/skills/` to use it across projects. Select `$unity-code-skill` for the coding workflow. For projects linked to YoFaAssets, start with their current shared source and the receiving game's rules.
