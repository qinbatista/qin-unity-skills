## Native lifecycle

Use these phases on one native timeline for the complete linked profile or when the receiving effect calls for them. Give each phase a real entry, behavior and exit. Keep the hit or protection window with its gameplay owner.

| Phase | Visible contribution | Runtime boundary |
| --- | --- | --- |
| Prepare | Establish the origin and initial seed with zero or minimal coverage. | Acquire or reset the instance, bind anchors and establish the actual start condition. |
| Preparing | Gather, draw, grow or assemble partial forms. | Advance the nonlinear shape and separate contributions over their authored windows. |
| Prepared | Hold a readable charged state. | Wait for the real release gate after visible preparation is complete. |
| Releasing | Extend lines, open arcs, expand surfaces or scatter particles. | Start from the prepared state when the actual release is accepted. |
| Released | Show the active form, impact and any controlled hold. | Observe the gameplay owner's active window and any independent residual presentation. |
| Retracting | Unwind, reverse-draw, shrink, absorb or disperse. | Stop new work at the correct event and retract from the current values. |
| Recycled | Return to the authored rest state with no effect coverage or stale tail. | Reset and release or return the exact acquisition. |

Resource readiness can precede the cycle. Verify first visible preparation as well as warm playback. On interruption, retract the current partial shape and record which stages were reached. Preserve immediate owner destruction where it is required and distinguish it from natural completion. Exercise normal completion, early and late cancellation, disable and another use of the same pooled slot.

## Progressive formation and layers

- For lines, use an advancing path, extension from an origin or ordered assembly. Leave the unreached path absent and shape width, emission and accents separately.
- For rings, use an advancing arc, expanding or contracting radius, or a closing assembly. Define direction, closure and the initial extent. Inspect the first visible frame for a prematurely complete contour.
- For surfaces or volumes, move the reveal or dissolve front, deform, grow or assemble coverage in the source's actual shape. Coordinate the surface with line and particle progression. Verify a specified surface with its real material and gameplay-scale coverage.
- For particles, define gathering, emission spread, travel and terminal scatter or absorption. Move from local following to world space where detached particles need to stay behind. Check age response and actual bounded tail completion.

Test early, middle and late geometry separately from opacity. Trace path coverage, angle, radius or assembly in the native output. Use the `unity-animation-skill` motion-curve rules for the actual resulting time response of each independent control. Preserve the real clock and action events while shaping the visual progression.

Choose depth, occlusion, contrasting scale and foreground/background balance to keep the subject readable. Compare attribute variants in grayscale by silhouette, flow, start, main timing and finish. Verify bound body or world anchors throughout the action and preserve the underlying collision or hit behavior.

## Use an existing effect or reference

1. Bind the action, viewing scale and actual trigger from the design. For new or revised motion, author and inspect a timed GIF before collecting technique references. Check the first and last frames and whether the action proceeds in the intended direction.
2. Search the game's declared reference source by technique, such as advancing path distance, front and back occlusion, or particles detaching into world space. Start with a suitable editable original. For YoFaAssets, follow the ID to its Prefab, graph, code or verified dependency closure. Try adapting the compatible parts before replacing them. Consult the primary article or source code for techniques the original does not cover. If no source can supply the technique, use the reviewed GIF for motion and record the source or compatibility gap. Record the mechanism, what works at game scale and timing, what must change, and the assets or code reused. Check license and renderer compatibility for intake.
3. Count the independent visual jobs in the GIF. Map each job to its adapted principle and record what would disappear when the job is disabled. An independently lingering wake and a contact burst can be distinct jobs within one cast.
4. Play each job alone and then restore the composition. Align the native action and GIF at the documented trigger and replay at gameplay speed and scale. Name the first visible cue, the travel and focal contact, what stays behind the actor, which secondary shapes must remain distinguishable, and what clears at the end. Review each requested form. Exercise the real outcome, interruption and reuse separately. For directional actions, follow the first visible mark from the source on both sides.
5. Keep the case open when a visual cue is weak, obscured, misplaced, mistimed or still visible at retirement. Mark the actual frame, inspect the contributing draws in isolation, and change their size, contrast, timing, depth or anchors as needed. Capture and inspect the same complete shot after the change. Revisit the reference interpretation and layer breakdown if local tuning leaves the same defect. Keep repairing and replaying while an in-scope correction remains available.
6. After the full composition and gameplay checks pass, link each applied reference to the receiving Prefab, graph, script or material. Record the behavior or bytes reused and show the repaired moment at matched timing. Write reusable Skill changes from the verified result.

For a motion fidelity request, mark the cue times, endpoints, subject-relative shape and the handoff from one visible layer to the next before evaluating the result. Compare those landmarks in the GIF and both complete native takes. Keep the native camera and playback speed. Scale the comparison panels uniformly to the same subject height when the drawn study uses a different camera. Follow the visible lead through each transition and correct its path, sorting or timing where it departs from the study.
